# 改名：Vluer 改为“续杯”

用户在 2026-09-29 从监工给出的候选里选定了“续杯”。含义：续费就像续杯。它和详情页里晃动的液面、玻璃质感的界面也对得上。

## 改什么

所有用户看得见的地方都改成“续杯”：

- 桌面图标下的名称（`strings.xml` 的 `app_name`）。
- 总览页头部。
- 启动画面。
- 通知的应用名、通知渠道的名称和说明。
- 设置页的“关于”、开源许可页。
- 通知权限说明、后台限制说明等文案里提到 app 名称的地方。
- 导出文件的默认文件名，改成 `xubei-backup-日期.json` 这种形式。
- 空状态、引导文案。
- README.md、THIRD_PARTY_NOTICES.md、tools/mock-komari/README.md。
- `settings.gradle.kts` 的 `rootProject.name` 改成 `Xubei`。

英文场合（文件名、工程名）用拼音 `Xubei`。

## 不改什么

- 包名和 applicationId 保持 `com.ftwegc.myapplication`。
- 项目目录名保持 `vluer-app`。
- 代码里的类名、函数名、资源名（例如 `VluerTheme`、`VluerApp`、`VluerDock`）保持不变。改它们没有用户价值，只会增加出错的机会。
- 通知点击用的内部链接前缀 `vluer://` 保持不变。
- 数据库文件名、DataStore 文件名保持不变，否则已有数据会丢。
- 旧的导出文件必须照样能导入。
- docs 目录下历史截图的文件夹名不用改。

## 新标志

设计稿：`docs/mockups/logo-xubei.html` 。用浏览器打开能看到各个尺寸和用途下的效果。实现时以它的 SVG 源码为准，里面的坐标、圆角、线宽、渐变色值都是具体数值，画布是 108×108。

构成：

1. **环**。圆心 (54, 55)，半径 36，线宽 5，圆头。占整圈的 74%，起点在左下，留出缺口。颜色是薄荷绿到蓝到紫的渐变。后面垫一圈很淡的完整底环。
2. **杯子**。上宽下窄的玻璃杯，杯口在 y=33，从 x=37 到 x=71。杯底在 y=78，两个底角是圆角。杯身用白色描边，线宽 2.2。杯身内部有一层很淡的玻璃渐变。
3. **液体**。液面在 y=52 附近，带一道波浪。颜色是薄荷绿到蓝的纵向渐变。液体被杯子的轮廓裁切。
4. **高光**。杯身左侧一道白色的斜线，圆头。
5. **底色**（只用于启动图标）。深青到深蓝到深紫的斜向渐变，左上角叠一团青绿色的光晕。

### 三个版本

| 版本 | 用途 | 说明 |
|---|---|---|
| 完整版 | 启动图标 | 带底色。做成自适应图标：底色是背景层，环和杯子是前景层。前景内容要落在中间 66dp 的安全区内 |
| 无底色版 | 启动画面、总览页头部、关于页、空状态 | 没有底色，直接放在流动背景或玻璃上 |
| 单色版 | 通知小图标、Android 13 的主题图标 | 只有轮廓和实心液体，单一颜色。通知小图标必须是纯白加透明 |

### 浅色背景

无底色版的杯身描边和高光是白色的，放在浅色背景上看不见。浅色模式下杯身描边和高光改用深色（接近 `#12234a`），环和液体的颜色不变。

### 动效

- 启动画面：环顺时针画出，液面从杯底升到正常高度，晃动两三下后静止。然后过渡到总览页。
- 总览页头部的标志：进入页面时液面轻轻晃一下。下拉刷新时液面升高，刷新完成回落。
- 下拉刷新指示器：用这只杯子，下拉越多液面越高，松手后环开始转动。
- 测试连接成功：杯子被注满，环闭合。
- 系统关闭动画时全部直接显示终态。

### 替换范围

全 app 所有用到旧标志（环加 V）的地方都换成新标志，不能有遗漏。包括启动图标的所有密度和形状、自适应图标、单色图标、通知小图标、启动画面、总览页头部、关于页、空状态插画、下拉刷新指示器、测试连接的动画、调试展示页。旧的标志资源文件删除。
