# Vluer 界面与动画规范

> **已被取代**：这是第一版的界面规范，已由 [design-brief-v2.md](design-brief-v2.md)（液态玻璃）取代，仅作历史记录保留，实现时不要再参照本文。

所有界面代码都要遵守这份规范。目标：看起来像一个用心打磨过的理财类 app，安静、清晰、有质感。动画服务于信息，不炫技。

## 视觉语言

- **基调**：深色优先，同时完整支持浅色。Android 12 以上默认不跟随壁纸取色，用自有品牌色，保证各机型观感一致。
- **品牌色**：主色为偏青的蓝绿（约 `#2DD4BF` 一带），辅色为暖琥珀（约 `#FBBF24` 一带，用于“即将到期”）。危险色用柔和的珊瑚红，不用纯红。具体色值由实现者在 Material3 色彩体系里调成完整的明暗两套 ColorScheme，并保证正文对比度不低于 4.5:1。
- **背景层次**：深色模式用三层表面色区分层级，不用纯黑。卡片用 20dp 到 28dp 大圆角，靠表面色差和极轻的描边区分，少用阴影。
- **首页头部**：支出总览卡用低饱和的渐变底（主色到深蓝），是全 app 唯一的大面积渐变。
- **字体**：数字是主角。金额和流量用量用大号、半粗、等宽数字（`fontFeatureSettings = "tnum"`），单位和货币符号用小一号、低强调色。
- **分类标识**：AI、VPS、其他各有固定的图标和色调，在列表、详情、图表里保持一致。
- **留白**：屏幕水平边距 20dp，卡片内边距 20dp，卡片间距 12dp。
- **空状态**：每个列表都要有空状态，含一个简洁的图形、一句说明和一个主操作按钮。

## 核心组件

- **流量环 / 流量条**：已用比例。低于 70% 用主色，70% 到 90% 渐变到琥珀，高于 90% 用珊瑚红。超过 100% 时进度满格并显示实际百分比文字。
- **到期徽标**：显示“还有 N 天”“今天到期”“已过期 N 天”，颜色随状态变化。
- **订阅卡片**：左侧分类图标，中间名称和周期，右侧金额和到期徽标。VPS 卡片底部带一条细流量条。
- **金额文本**：整数和小数部分字号不同，货币符号靠左上对齐。

## 动画规范

统一使用一套动效参数，定义在 `ui/theme/Motion.kt`，不要在各处写魔法数字。

| 场景 | 做法 |
|---|---|
| 页面切换 | 前进：新页面从右侧 1/10 宽度处滑入并淡入。返回相反。时长约 300ms，用 emphasized 缓动。底部标签之间切换用淡入淡出加轻微缩放 |
| 列表到详情 | 用共享元素过渡（`SharedTransitionLayout`）：卡片的图标、名称、金额平滑变形到详情页头部 |
| 列表项出现 | 首次进入时自上而下依次淡入上移，每项间隔约 40ms，最多错开 8 项 |
| 列表增删和排序 | `animateItem()`，让条目平滑移动 |
| 数字变化 | 金额和流量数值用滚动计数动画，从旧值过渡到新值，约 600ms |
| 流量环和进度条 | 进入时从 0 增长到目标值，用弹簧动效，略带回弹。颜色随比例平滑过渡 |
| 按压反馈 | 卡片按下缩小到 0.98，松开回弹。配合轻触感反馈 |
| 下拉刷新 | 使用 Material3 的 `PullToRefreshBox`，刷新完成后数值用计数动画更新 |
| 加载 | 用骨架屏加微光扫过效果，不用居中转圈 |
| 展开和收起 | `AnimatedVisibility` 配合 `expandVertically` 和淡入。编辑页里选择 VPS 分类时，VPS 专属字段用这种方式展开 |
| 状态切换 | 内容、加载、错误、空状态之间用 `AnimatedContent` 交叉淡化 |
| 底部导航 | 选中项图标有轻微弹跳，指示器平滑滑动 |
| 悬浮按钮 | 列表向下滚动时收缩为图标，向上滚动时展开文字 |
| 成功反馈 | 保存、标记已续费成功后，有一个短促的对勾动画 |

## 约束

- 尊重系统的“移除动画”设置。动画时长缩放为 0 时，所有动画直接跳到终态，功能不受影响。
- 动画不能阻塞操作。用户在动画过程中点击必须立即响应。
- 列表滚动保持流畅。动画只改 `graphicsLayer` 属性（透明度、位移、缩放），避免触发重新布局。
- 支持边到边显示（edge-to-edge），正确处理状态栏、导航栏和输入法的内边距。
- 所有可点击元素的触摸区域不小于 48dp，图标要有内容描述。
- 界面文字全部放在 `strings.xml`，中文。
- 每个页面和主要组件都要有 `@Preview`，包含深色和浅色两种。
