# Vluer 界面规范 v2：液态玻璃

这份规范取代 `design-brief.md`。用户看过第一版后的原话：“你的布局我不喜欢，要液态玻璃的，图表多一些，弄得有标志一些，代表的，我自己一个人用”。

第一版的问题：规整但普通，像任何一个 Material 应用。圆角卡片从上到下堆叠，信息靠文字和数字呈现，没有记忆点。

v2 的目标：打开就能认出这是 Vluer。玻璃质感、流动的色彩、用图表说话。

## 零、效果图是最高依据

布局由监工亲自设计，效果图在 `docs/mockups/`：

- `vluer-screens.html`：总览、订阅、详情、统计、新增订阅五个页面的完整布局。
- `home-liquid-glass.html`：总览页的早期单页版本，以 `vluer-screens.html` 为准。

用浏览器打开就能看到动效。实现时，布局、间距比例、图表种类和位置、玻璃层级、配色都以效果图为准。本文档的文字用来解释效果图表达不了的部分。两者冲突时以效果图为准。

效果图里的字母图标只是占位。真机上用各服务自己的标志，规则见第四节。

效果图没有画的页面（设置、Komari 面板设置、节点导入、编辑订阅的完整表单、各类对话框）沿用同一套材质和组件自行设计，风格必须和效果图一致。


## 一、不变的部分

以下内容沿用，不要动：

- 全部业务逻辑、数据层、Komari 对接、通知、后台任务、导出导入。
- 全部现有测试。界面重做不能让任何一条测试失败。
- 系统关闭动画时直接到终态。
- 界面文字放 `strings.xml`，中文。
- 动效参数集中定义，不写魔法数字。

## 二、液态玻璃材质

液态玻璃不是“半透明加模糊”。它有四个特征，缺一不可：

1. **背景模糊**。玻璃后面的内容被模糊，能看出颜色和大致形状。
2. **折射**。玻璃边缘附近，背后的内容有轻微的弯曲变形，像透过一块有厚度的玻璃。
3. **高光边**。玻璃边缘有一圈细的亮边，亮度沿边缘变化，左上更亮，模拟光源。
4. **会动**。按下时玻璃轻微形变和提亮，滚动时背后内容透过玻璃流动。

### 实现分级

| 系统版本 | 效果 |
|---|---|
| Android 13 及以上 | 完整效果：模糊、折射、高光，用 `RuntimeShader` 实现 |
| Android 12 | 模糊和高光，没有折射 |
| Android 11 及以下 | 半透明着色面板加高光边，没有模糊 |

三档都要好看，低版本不能是一块灰色方块。

### 技术选择

已由监工决定，详见 `docs/oss-research.md`：

- 玻璃效果用 `io.github.kyant0:backdrop:1.0.6` 和 `io.github.kyant0:shapes:1.2.0`，版本不能升级。
- 这个库不会自动降级。Android 11 及以下要自己判断系统版本，画更不透明的底色。
- 玻璃叠玻璃必须用 `exportedBackdrop`，否则会崩溃。
- 不管底层怎么实现，都封装成项目自己的 `GlassSurface` 组件，界面代码只依赖这个组件，不直接调用库。

### 材质规格

- **玻璃层级**分三种：薄玻璃用于小标签和按钮，标准玻璃用于内容面板，厚玻璃用于导航栏和弹层。厚度越大，模糊越强，着色越明显。
- **着色**。玻璃可以带一点颜色，比如 AI 类带紫，VPS 类带蓝，告警带琥珀或珊瑚红。着色要淡。
- **文字可读性是硬性要求**。玻璃上的正文对比度不低于 4.5:1。背景颜色太亮时，玻璃要自动加深着色。
- **性能**。列表滚动保持流畅。同屏的模糊层数量要控制，列表里的小元素用薄玻璃或不模糊。

## 三、背景

玻璃要有东西可透才好看，所以背景不能是纯色。

- **流动的色彩场**。几团大的、柔和的色块缓慢漂移和变形，像极光。深色模式下是深底上的彩色光晕，浅色模式下是浅底上的淡彩。
- **背景有含义**。色彩随状态变化：一切正常时是青绿和蓝；有订阅快到期时混入琥珀；有流量超限或已过期时混入珊瑚红。打开 app 不用读字就能感觉到状态。
- **各页面色调不同**但属于同一套。
- 漂移速度很慢，不抢注意力。系统关闭动画时静止。

## 四、标志与辨识度

### App 自己的标志

- 设计一个 Vluer 标志：一个有玻璃质感的图形，不是简单的字母加渐变底。要能在很小的尺寸下认出来。
- 同一个图形出现在启动图标、启动画面、总览页头部、空状态、通知图标里。
- 启动画面：标志带一次玻璃折射的光扫过，然后过渡到首页。
- 定一个标志性的视觉符号贯穿全 app。建议用“环”：流量是环，到期倒计时是环，支出占比是环，标志本身也含环的元素。

### 每个订阅的代表性图标

现在所有 AI 订阅是同一个图标，所有 VPS 是同一个图标，分不出谁是谁。改成：

- **内置一组常见服务的图标**，按订阅名称自动匹配。AI 类至少覆盖 ChatGPT / OpenAI、Claude / Anthropic、Gemini / Google、Copilot / GitHub、Cursor、Midjourney、Perplexity、Grok、DeepSeek、Kimi、豆包、通义。VPS 和云厂商至少覆盖甲骨文、AWS、Vultr、搬瓦工、RackNerd、DigitalOcean、Hetzner、阿里云、腾讯云、RUVDS、JustHost。其他常见订阅覆盖 iCloud、Apple、Spotify、Netflix、YouTube、Telegram、1Password、JetBrains、Notion。
- 图标来源用 Simple Icons（CC0 许可）的矢量路径，转成 Android 矢量图。只拿确实需要的这些，不要整包引入。app 仅供个人使用，图标只用于识别订阅对应的服务。
- **匹配不到时生成字母标记**：取名称的首字母或首个汉字，配一个由名称算出来的固定颜色。同一个名称永远是同一个颜色。
- **VPS 显示国旗**。Komari 节点的 `region` 字段是国旗表情符号。VPS 图标的角上叠一个国旗小标。
- **用户可以手动改**：在编辑页选内置图标、选颜色，或者用相册里的图片。
- 图标放在一块小的玻璃底座上，带该服务的代表色着色。

## 五、布局

放弃“大标题加卡片纵向堆叠”。

### 导航

- **悬浮的玻璃导航栏**。胶囊形，悬浮在屏幕底部，不贴边，背后内容透过它流动。选中项是一颗会在选项之间滑动和形变的玻璃液滴。
- **四个标签**：总览、订阅、统计、设置。
- 向下滚动时导航栏收缩变小，向上滚动时恢复。
- 新增按钮是一颗独立的玻璃圆钮，和导航栏并排悬浮。

### 总览页：便当盒网格

用大小不一的玻璃块拼成网格，不用等宽的列表。

- **主块**，占满宽度。本月支出大数字，加一条支出节奏曲线。
- **到期环**，占半宽。最近要到期的那个订阅，大环显示剩余天数，中间是该订阅的图标。
- **流量总览**，占半宽。几个同心环，每环一台 VPS。
- **即将到期时间轴**，占满宽度。横向的时间轴，未来 30 天，每个订阅的图标钉在对应日期上。
- **节点状态条**，占满宽度。每台 VPS 一小格，显示在线状态和实时网速的迷你曲线。
- **分类占比**，占半宽。环形图。
- **年度预估**，占半宽。大数字加迷你柱状图。

块的排列要有节奏，不要每块一样高。

### 订阅页

- 顶部是横向滚动的分类筛选，玻璃胶囊。
- 订阅项可以在两种视图间切换：**列表视图**是紧凑的玻璃条；**网格视图**是方形玻璃块，图标大，信息少。
- 每项左侧是代表性图标，右侧是一个小的到期环，不只是文字徽标。
- VPS 项带迷你流量曲线。

### 详情页

- 头部是沉浸式的：该订阅的代表色铺满背景色彩场，大图标在玻璃底座上，可以随滚动缩小并停靠到顶栏。
- 内容分成几块玻璃面板，每块以图表为主。

### 统计页（新增）

全是图表，见下一节。

### 弹层和对话框

- 底部弹层、菜单、对话框全部是厚玻璃，背后内容模糊可见。
- 弹出时玻璃从触发它的按钮处生长出来。

## 六、图表

所有图表自己用 Compose Canvas 画，不引入图表库。这一点已核实过：市面上的图表库做不出环、仪表、热力图的玻璃风格，而且新版本都和本项目的 Kotlin 版本不兼容。风格统一：线条圆润，填充用渐变，带进入动画，可以点选查看数值。

### 支出类

| 图表 | 位置 | 内容 |
|---|---|---|
| 支出节奏曲线 | 总览主块 | 本月每天的累计应付金额，平滑曲线加渐变填充 |
| 分类占比环 | 总览、统计 | AI、VPS、其他各占多少，可点选 |
| 订阅占比条 | 统计 | 每个订阅占总支出的比例，横向堆叠条，按金额排序 |
| 月度支出柱状图 | 统计 | 过去和未来各 6 个月的每月应付金额，未来的用半透明表示 |
| 年度预估 | 总览、统计 | 全年总额，加每月分布 |
| 缴费日历热力图 | 统计 | 一个月的日历格子，有缴费的日子着色，金额越大颜色越深 |
| 单个订阅的累计花费 | 详情 | 从开始订阅到现在一共花了多少，阶梯状曲线 |

### 到期类

| 图表 | 位置 | 内容 |
|---|---|---|
| 到期环 | 总览、列表、详情 | 本周期已过的比例，中间是剩余天数 |
| 到期时间轴 | 总览、统计 | 未来 30 天或 90 天，订阅图标钉在日期上 |

### 流量类

| 图表 | 位置 | 内容 |
|---|---|---|
| 同心流量环 | 总览 | 每环一台 VPS 的用量比例 |
| 流量环 | 详情 | 已用比例，颜色随用量变化。环里有液体晃动的效果，用量越高液面越高 |
| 每日用量柱状图 | 详情 | 已有，改成玻璃风格，上行和下行用两种颜色堆叠 |
| 用量预测线 | 详情 | 按当前速度，到周期结束时会用到多少。实线是已发生，虚线是预测，横线是限额 |
| 上下行对比 | 详情 | 上行和下行的比例 |
| 各 VPS 用量对比 | 统计 | 横向条形图，按用量排序 |
| 历史周期对比 | 详情 | 已有，改成柱状图 |

### 节点实时状态类

Komari 的 `/api/recent/{uuid}` 返回最近约一分钟的上报，每条都有 CPU、内存、硬盘、负载、实时网速。这些数据之前没用上。

| 图表 | 位置 | 内容 |
|---|---|---|
| 实时网速曲线 | 详情、总览状态条 | 最近一分钟的上行和下行速率，两条曲线 |
| CPU 和内存迷你曲线 | 详情 | 最近一分钟 |
| 资源仪表 | 详情 | CPU、内存、硬盘三个小的半圆仪表 |
| 在线状态点 | 各处 | 在线时是会呼吸的光点 |

详情页停留时，实时数据每隔几秒刷新一次，离开页面就停。

### 数据不足时

图表没有足够数据时，显示占位图形和一句说明，不显示空坐标轴。

## 七、动效

沿用第一版的全部动效要求，并增加：

- **玻璃按压**。按下时玻璃向下凹、提亮、边缘高光移动，松开回弹。
- **液滴指示器**。导航栏选中项在选项之间移动时，先拉长再收缩，像液滴。
- **滚动折射**。内容在玻璃导航栏和顶栏后面滚动时，透过玻璃能看到流动。
- **图表进入**。曲线从左到右画出，柱子依次生长，环顺时针画出，数字同步计数。
- **液面晃动**。流量环里的液面在进入时晃动几下再静止。
- **便当盒入场**。总览页的玻璃块依次浮现，带轻微的缩放和位移。
- **形变过渡**。列表项到详情页，玻璃块本身变形成详情页的头部。

## 八、个人自用的取舍

app 只有用户自己用，所以：

- 不做新手引导和功能介绍页。
- 默认深色。浅色模式保留，要同样好看。
- 默认值按用户的实际情况设置：默认货币、默认提醒天数等保持可改。
- 调试入口可以保留在设置页里，不用藏。
- 不为了兼容极老的设备牺牲效果。最低支持版本不变，但视觉优先保证 Android 13 及以上。

## 九、验收标准

- 和第一版的截图并排看，一眼能看出是完全不同的设计。
- 任取一个页面截图，不看文字也能认出是 Vluer。
- 总览页不滚动就能看到至少 4 种图表。
- 玻璃上的文字在任何背景色下都清晰可读。
- 列表和总览滚动流畅，没有明显掉帧。
- 每个订阅都有能代表它的图标，没有两个不同服务共用同一个通用图标。
